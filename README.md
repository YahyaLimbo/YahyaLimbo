## 👋 About me

I'm Yahya, a Computer Science graduate from Nottingham Trent University. I build
AI and robotics software: ROS 2 stacks that run on both simulated and real
hardware, and perception models trained on synthetic data generated in NVIDIA
Isaac Sim and Gazebo.

Based near Bologna, Italy. Open to AI, computer vision and robotics software
roles in Italy and German-speaking Europe. Fluent in Italian and English,
currently learning German.

## 🚀 Featured projects

| Project | What it is |
|---|---|
| **[myCobot 280 ROS 2 stack](https://github.com/RAISE-NTU/mycobot_280_ros2)** | ROS 2 Humble stack where one codebase drives both an Ignition Gazebo simulation and the physical arm over USB from a Jetson AGX Orin. MoveIt 2 planning, a C++ `ros2_control` hardware interface, and a unit-tested serial protocol layer. |
| **[Woodland-Sim](https://github.com/YahyaLimbo/Woodlan-Sim)** | BSc thesis: a high-fidelity woodland environment in Isaac Sim and Gazebo for generating synthetic training data. Semantic segmentation reaches **73.4% mIoU** over 12 plant classes; YOLOv8m reaches **0.76 mAP@50** for plant detection. Dataset and weights archived on Zenodo. |
| **[Botanical AI assistant](https://github.com/YahyaLimbo/Botanical-chatbot)** | Plant-care assistant built with Azure OpenAI and Semantic Kernel, combining retrieval-augmented generation, first-order logic, fuzzy logic and image classification. |
